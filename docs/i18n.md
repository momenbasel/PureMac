# Qpure 国际化说明

Qpure 使用 macOS 原生 `.lproj/Localizable.strings` 管理界面文案。用户可在「设置 → 通用 → 语言」选择跟随系统或指定语言；切换后重启应用生效。

## 已支持的语言

- English (`en`)
- Français (`fr`)
- Español (`es`)
- 日本語 (`ja`)
- العربية (`ar`)
- Português (Brasil) (`pt-BR`)
- Polski (`pl`)
- Русский (`ru`)
- Українська (`uk`)
- 简体中文 (`zh-Hans`)
- 繁體中文 (`zh-Hant`)

## 添加或修改翻译

1. 在 `PureMac/<locale>.lproj/Localizable.strings` 添加与英文资源完全相同的 key。
2. 修改设置项或菜单文字时，同步检查 `InfoPlist.strings` 和 `ServicesMenu.strings` 中的系统显示文案。
3. 保留 `%@`、`%lld`、`%%` 等格式占位符的数量和顺序，不翻译应用名、路径、命令及系统 API 名称。
4. 运行 `PureMacTests/LocalizationFilesTests.swift` 中的资源检查，确认 key 完整、格式占位符兼容且无重复。

新增界面文字应使用 SwiftUI 的本地化字符串键（例如 `Text("... ")`），不要将面向用户的文案写成不可本地化的动态字符串。
